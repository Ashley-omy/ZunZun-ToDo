# ADR 0001 — Use Spring Boot 4.1 Instead of 3.5

- **Status:** Accepted
- **Date:** 2026-10-19

## Context

The design specification first targeted Spring Boot 3.5. Open-source support for 3.5 ended on 30 June 2026,
and Spring Initializr no longer offers it. Staying on 3.5 would mean writing the build by hand and shipping
v1.0 on a release that no longer gets free security fixes.

## Decision

Build the backend on **Spring Boot 4.1.x** (4.1.1 when the project was created), with Java 25.

## Consequences

- Open-source support runs until 31 July 2027. Moving to 4.2 (due 30 Nov 2026) is a small upgrade after v1.0.
- The project is generated by Initializr, Maven Wrapper included. No hand-written `pom.xml` is needed.
- Boot 4 changes that affect the code:
  - modular starters (`spring-boot-starter-webmvc`, `spring-boot-starter-flyway`, OAuth2 starters renamed under `spring-boot-starter-security-oauth2-*`) and matching test starters
  - Spring Framework 7, Spring Security 7, Hibernate 7, Jakarta EE 11
  - Jackson 3 (`tools.jackson.*`)
  - Testcontainers 2 (`testcontainers-postgresql`, `org.testcontainers.postgresql.PostgreSQLContainer`)
  - springdoc-openapi 3.x
- Many tutorials still target Boot 3, so examples from them have to be adapted.
